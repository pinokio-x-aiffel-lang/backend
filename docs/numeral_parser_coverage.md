# 수사 파서 — 현재 구현 룰 & 미커버 결정

> **대상**: `src/modules/normalize_claim.py` 의 **실제 런타임 룰** — `_parse_value`(value 슬롯) / `_normalize_period`(period_value 슬롯).
> **목적**: "지금 코드가 실제로 무엇을 변환하고, **무엇을 의도적으로 룰로 안 하는가**"의 단일 출처.
> **목표 스펙과 구분**: 향후 통합 파서(`parse_numeric_expression.py`, 약·안팎·수십 등 풀세트)의 **설계 명세**는 `docs/numeric_expression_parsing.md`. 본 문서는 **현재 구현 현황·커버리지**다.
> **룰 실패(None) 시**: value → `_llm_normalize_value` LLM 폴백 / period → base 있으면 LLM 폴백, base 없으면 차단(`_llm_period_blocked`).
> **근거 벤치마크**: `benchmark/260617_3_nl-numeric-expr_leeaain/` (72개 표현 실측).

## 1. value 룰 — `_parse_value` (시도 순서)

`_try_range → _try_change → _try_ratio → _parse_korean_numeral_rule → _parse_number_rule`

| 계열 | 함수 | 예 → 결과 |
|---|---|---|
| 범위·경계 | `_try_range` | `1850~1950원`→`1850~1950`, `100만~200만`→`1000000~2000000`, `30% 이상`→`>=30`, `50명 미만`→`<50`, `최대 3조`→`<=3e12`, `5천 명부터 1만 명까지`→`5000~10000` |
| 증감 | `_try_change` | `5.2% 증가`→`+5.2`, `21만6000명 증가`→`+216000`, `2배`→`2.0`, `갑절`→`2.0`, `급증`→`+`(방향만) |
| 배수(native) | `_try_change` | `두 배`→`2.0`, `세 배`→`3.0` … `열 배`→`10.0` (아래 §5) |
| 비율·분수 | `_try_ratio` | `3대 5`→`3:5`, `3분의 1`→`0.3333`, `1/3`→`0.3333`, `2할 5푼`→`0.25`, `절반`/`과반`→`0.5`, `3.1%`→`3.1`(%는 ÷100 안 함·`unit`에 보존) |
| 한국어 수사 | `_parse_korean_numeral_rule` | `1조 2천억`→`1200000000000`, `5천4백만`→`54000000`, `350만 가구`→`3500000` |
| 아라비아+단위 | `_parse_number_rule` | `1,250원`→`1250`, `2290억원`→`229000000000`, `21만6000명`→`216000` |

## 3. 의도적 미커버 (룰 비대상 — LLM 폴백 / NEI로 위임)

> **결정**: 아래 표현들은 룰로 점추정하면 **거짓정밀·외부지식·모호**가 되어 오히려 위험하므로 **룰에서 의도적으로 다루지 않는다**. None 반환 → 런타임 폴백 또는 미추출.

| 표현 | 분류 | 룰 제외 이유 | 런타임 처리 |
|---|---|---|---|
| `코로나 이전` | 이벤트 기준 상대시점 | "코로나 시작 시점"이라는 **외부 지식** 필요, 연·월 환산 룰화 불가 | period LLM 폴백 또는 NEI |
| `올 들어` | 누적 기간 | "올해 1월~현재"는 **단일 시점이 아님**(구간), 슬롯 모델과 불일치 | 미정규화 |
| `최근` | 모호 시점 | 기준 폭(최근 1개월? 1년?)이 **미정의** | 미정규화 |
| `사상 최대` | 정성 극값 | **수치가 아님**(서술). value 슬롯 대상 아님 | 미추출 / NEI |
| `두 자릿수` | 자릿수 범위 | 10~99 범위라 **점추정=거짓정밀**(예: 임의로 10/99 박으면 오답) | 미정규화 |
| `거의 절반` | 근사 정성비율 | `절반`단독은 `0.5`로 커버하나, "거의"의 **방향(미만/근접) 모호** | 미정규화 |

→ 공통 원칙: **외부지식 의존 · 구간/모호 · 정성표현**은 룰화하지 않는다. 점추정보다 None(폴백/NEI)이 안전.

## 4. 배수 정책 (§1 보강)

- **bare native 수사 + 배** 만 커버: `한/두/세/네/다섯/여섯/일곱/여덟/아홉/열` + `배` → 배율값. `두 배`→`2.0`(아라비아 `2배`·`갑절`과 parity). 구현: `_NATIVE_MULT` 맵 + `_try_change`.
- **조사·경계 결합형은 미커버**(의도적): `두 배로`(→None), `두 배 이상`(→`>=두 배`, 깨짐). `이상`형까지 `>=2`로 정규화하려면 `_try_range` 안쪽 파서에 수사-배를 태워야 하므로 **보류**(추후 보강 후보 §5).
- 배수값의 의미(×2 절대값인지 +100% 증가인지)는 value 슬롯이 결정하지 않음 — 7·8단계 판정의 몫. `2배`와 동일.

## 5. 알려진 silent-wrong (추후 보강 후보, 현재 미수정)

> 룰 미스(None)가 아니라 **그럴듯한 오답**이 나오는 케이스. `202503→202,503`과 동일 계열의 위험. 실측: `benchmark/260617_3_nl-numeric-expr_leeaain/`.

| 표현 | 현재 결과 | 기대 | 원인 |
|---|---|---|---|
| `7:3` | `73` | `7:3` | 콜론 비율 미지원(`3대5`는 정상) |
| `4명 중 1명` | `41` | `0.25` | "중/당/꼴" 비율 구문 미지원 |
| `3명에 1명꼴` | `31` | `0.3333` | 〃 |
| `수십만`·`수백억`·`십수 명` | `100000`·`1e10`·`10` | 범위/None | 미정량 어림을 점추정(거짓정밀) |
| `두 배 이상` | `>=두 배` | `>=2` | range 안쪽 수사-배 미파싱(§4) |
| `1위`·`상위 10%`·`톱5` | `1`·`10`·`5` | 순위 슬롯 | 순위·서수 의미 소실 |

우선순위(권장): ① "중/당/꼴" 비율 → ② 미정량 어림 점추정→None/range → ③ 순위 별도 슬롯.
