## 패턴 2 — 부분 성공: 맞는 통계 영역이지만 정확한 표가 아닐 때

**"소비자물가지수"** 검색 시 1~2위가 IMF/OECD 국제통계 표가 차지하고, 통계청 소비자물가조사 표는 3위부터 나온다.

```
[24] subject: 소비자물가지수
  1위: 소비자물가지수 (IMF) → DT_2IFS002
  2위: 소비자물가지수 (OECD) → DT_2OEEO0121
  3위: 품목성질별 소비자물가지수(2020=100) (통계청) → DT_1J22002  ← 실제 정답
```

**"소비자물가 상승률"** 검색 시 8위까지 내려가야 "월별 소비자물가 등락률" 표가 나온다.

```
[26] subject: 소비자물가 상승률
  1위: 기대인플레이션율 (한국은행) → 엉뚱함
  8위: 월별 소비자물가 등락률 (통계청) → DT_1J22042  ← 실제 정답
```

**"가계소득"** 검색 시 상위 표들이 모두 "가계수지" (지출 포함) 표. 수입 측면의 소득 표는 없음.

## 패턴 3 — 실패: subject가 과도하게 구체적이거나 "한국"이 포함될 때

extractor가 너무 구체적인 subject를 뽑으면 KOSIS 검색이 엉뚱한 곳으로 간다.

| subject | 1위 표명 | 문제 |
|---|---|---|
| 한국 인구 | 한국어 학습 경험 유무 및 학습기관(이민자) | "한국" → 이민자 통계로 오염 |
| 고용원 없는 자영업자 수 | 장애인 취업자의 종사상 지위 | 너무 구체적, 매칭 실패 |
| 근로자 중 초단기 근로자 비율 | 해외여행, 거주 경험 및 기간 | 완전 무관한 결과 |
| 한국 근로자 주당 평균 근로시간 | 주요 직장에서의 평균 주간 근로 시간(OECD) | OECD 표가 1위 |
| 첫 직장 근로 형태 중 시간제 근로자의 비율 | 결과 없음 | 너무 구체적 |

**핵심 원인:** extractor가 원문 문장 표현을 그대로 subject로 뽑아서 KOSIS 검색어로는 부적절한 수준의 구체성.

---

## 패턴 4 — 실패: "청년" 키워드 오염

"청년 고용률"처럼 "청년"이 포함되면 top 10이 **시군구 지방 통계**로 채워진다.

```
[16] subject: 20대 이하 청년 고용률
  1위: 청년 경제활동 (전라남도 곡성군)
  2위: 청년 경제활동 (전라남도 보성군)
  3위: 청년 경제활동 (전라남도 고흥군)
  ...10위까지 전부 시군구통계
```

KOSIS의 랭킹 알고리즘이 "청년 + 경제활동"을 지방 시군구통계 표로 매핑하는 버그성 패턴.  
→ **"청년실업률", "청년고용률"처럼 붙여쓰거나 공백 제거 처리가 필요함.**

## 패턴 5 — 문장 품질 문제

extractor가 claim을 추출하지 못한 5건:

- 수치 없는 **정책 발표문** ("통계청은 12월까지 개발할 예정")
- **메타데이터 노이즈** 포함 문장 ("14:55 통계청이 올해...")

→ 문장 선별 단계에서 타임스탬프 패턴 필터링 강화 필요.

## 개선 제안

1. **subject 전처리**: 공백 제거(`"청년 고용률"` → `"청년고용률"`), "한국" 접두어 제거
2. **KOSIS 검색 필터**: 시군구통계(`org_nm`에 "군", "시" 포함) 후보 우선순위 낮춤
3. **국제통계 필터**: IMF/OECD/UN 표는 국내 통계청 표 없을 때 fallback으로만 사용
