## 4. 라벨 14건 다른 이유 — 데이터는 동일

KOSIS가 같은 표를 **2개 트리에 동시 등록**. 어디서 먼저 발견했냐만 다름.

예시 (14건 모두 행안부 `orgId=110` 안전·재난 통계):

| tblId | 아인님 | async |
|---|---|---|
| `DT_110034_A001` | `MT_OTITLE` / `110_002` | `MT_ZTITLE` / `C_004` |
| `DT_110034_B001` | `MT_OTITLE` / `110_002` | `MT_ZTITLE` / `C_004` |
| ... (14건) | | |

→ 매칭 키 `(orgId, tblId)` 동일하므로 후속 단계 영향 없음.
